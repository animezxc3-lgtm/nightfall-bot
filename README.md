# Lelouch Bot v2

Переписанная версия VK-бота сообщества NightFall с чистой архитектурой.

## Что сделано

Полный перенос основных систем старого бота в новую структуру.

### Архитектура
- Роутер команд с декораторами (вместо гигантских if-elif)
- Слой сервисов (бизнес-логика отдельно от хэндлеров)
- Версионированные миграции БД
- Централизованное логирование с ротацией
- Конфиг только через `.env`
- Type hints, аккуратная обработка ошибок

### Перенесённый функционал

| Система | Команды / возможности |
|---------|----------------------|
| **Базовое** | меню, профиль, баланс, ник, помощь, активность |
| **RP** | все RP-команды + adult только с партнёром + фото из кэша |
| **Работа** | устроиться, работать, уволиться, работа [@user], повышение |
| **Магазин** | дом / машина / телефон, продать |
| **Отношения** | встречаться, расстаться, создать брак, развод, семья, уйти из семьи |
| **Казино** | деп / рулетка |
| **Переводы** | передать @user сумма |
| **Дуэли** | дуэль @user + кнопки |
| **Создатель** | выдать / отобрать ресурсы |
| **Кнопки** | меню, hire, relationship/marriage/duel |
| **Служебное** | приветствия, стартовые монеты, счётчик сообщений, бан |

### Что упрощено (можно дописать поверх каркаса)

- Полная админка (варны, кики, чистка, закрепы)
- Система заявок
- Нормы / еженедельные отчёты и задания
- Картинка рулетки (Pillow)
- VIP-магазин и покупка множителя зарплаты
- Твинки (команды)
- Усыновление / выгон из семьи

## Структура

```
lelouch_bot/
├── main.py
├── requirements.txt
├── .env.example
├── bot/
│   ├── core/           # config, database, router, logging
│   ├── handlers/       # команды и кнопки
│   ├── services/       # RP, work, shop, relationships, games...
│   ├── keyboards/
│   └── utils/
├── data/
└── logs/
```

## Запуск

```bash
cd lelouch_bot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполнить VK_TOKEN, VK_GROUP_ID, CREATOR_ID
python main.py
```

Старую `bot.db` можно положить в `data/` — схема совместима.

## Важно

1. Токен из старого архива — **перевыпусти**.
2. Не коммить `.env`.
3. Логи: `logs/bot.log`.
